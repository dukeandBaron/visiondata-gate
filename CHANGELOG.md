# Changelog

Notable changes are recorded here using the structure of
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Entries describe the indicated source/release, not customer acceptance or
production authorization. The current Python package metadata is `0.1.0`;
competition artifact tags are not a claim of a matching PyPI package version.

## [Unreleased]

### Added

- Explicit per-sample acceptance and named annotation-version review before
  freezing an operator project; metadata-only offline compute handoff.
- Local reference-learning lifecycle and React `/learning` integration: frozen
  sample membership, human feedback, new-Gate evidence linking, normal-negative
  declarations and explicit next-round input.
- Source quickstart and primary-interface/support boundaries, review-response
  tracking, and software citation metadata.
- Independently locked quality tooling, scoped Python types, exact line/branch
  coverage and testcase-identity gates, security scan workflows and contributor hooks.
- Public balanced DynamicBench-v3 reproducibility subset, raw fixed-set injection
  evidence, and explicit API/whole-chain-rewrite trust boundaries.

### Fixed

- Unknown learning writes retain their operation identity for explicit GET
  reconciliation; pre-dispatch rejection is distinct from an untrusted response.
- Stale read results no longer authorize learning actions. Same-project
  connection refreshes preserve unfinished review forms.

### Security and compatibility

- Production decisions remain human-controlled. New-Gate feedback evidence does
  not automatically close an issue, and val/test samples do not auto-enter train.
- Source changes above are not a statement that an older release/installer or
  PyPI distribution contains them. Review, freeze and publish separately.
