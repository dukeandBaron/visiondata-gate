# 数据、隐私、许可与行业边界

## 数据范围

初赛主 Demo 使用固定 seed 自生成图像、程序化 mask、corruption manifest 和隐藏 reserve。它们只能证明冻结工具和门禁流程在这些受控案例上可运行，不能证明真实现场缺陷识别能力。

公开数据集若被引用，提交材料至少记录：

- 官方来源与数据集名称
- 下载日期和版本/文件哈希
- 原始许可文本或许可核验状态
- 是否允许再分发、派生和商业演示
- 实际使用的样本范围与处理方法

许可未核清时只提供来源与下载说明，不将原始数据放入作品包。

## 企业与人员数据

真实工业图像可能包含设备结构、工艺参数、地点、人员面部、工牌、屏幕、时间和客户标识。处理真实数据前必须由数据所有者确定：

- 收集目的与最小必要字段
- 存储位置、保留期和删除流程
- 可访问角色和导出范围
- 人员告知、同意或其他合法依据
- 是否允许发送给外部模型或云服务

默认策略是本地离线；`raw/`、`incoming/`、企业 workspace、个人目录和秘密配置不得进入公开包。若后续接入外部模型，只发送经授权、最小化的结构化摘要，并在运行记录中披露提供商、模型、发送字段和失败降级。

## 凭据与构包

构包前后检查私钥头、常见 API key/token 前缀、云访问 key 和长秘密赋值模式。发现疑似凭据即阻断构包，只报告模式和位置，不回显值。SHA-256 用于完整性核验，不等于加密、访问控制、真人签名或法律存证。

本地产品运行态位于 `output/product/`，包含 SQLite 用户/工作区/项目/任务索引及每任务证据。源码构包会排除 `output`，并额外按后缀排除 `.db`、`.sqlite`、`.sqlite3` 及 WAL/SHM sidecar，防止环境变量改动运行根时把本地成员信息或任务历史带入公开 ZIP。海康 / Omni 数据源在授权、驻留与脱敏范围未确认前保持 `not_connected`，不得复制进项目或参赛包。

## 代码与依赖许可

当前代码的“开放源码发布”在以下条件完成前保持 `NO-GO`；这不阻止形成带明确边界的比赛提交候选包：

- [ ] 权利主体确认顶层 LICENSE
- [ ] 补齐正式第三方 NOTICE，并处理清单中 8 项 `REVIEW_REQUIRED`
- [x] 固化 `uv.lock` 与锁定依赖来源
- [x] 生成 CycloneDX 1.6 SBOM 与第三方许可证元数据清单
- [ ] 在对外开源前核对图标、字体、截图和派生代码许可

比赛材料可以写“提供可复用 Agent schema、白名单工具接口、合成样例、SBOM 与 manifest 模板”，不能写“已完全开源”或“已经过法律审查”。

## 行业边界

`PASS` 仅表示批次满足冻结数据合同，可以进入 `sandbox_experiment_training_pool`。它不表示：

- 产品、零件或设备质量合格
- 训练模型有效、无偏或达到生产指标
- 数据已经获得完整授权
- 产线、人员或环境安全得到认证
- AI Council 等同于真人工程师、质检员或法定责任人

生产训练、对外发布、产线部署与安全关键使用必须由真实授权主体重新审查。工具未覆盖的现场事实不得由 AI 推断补齐。
