# VisionData Gate 最小体验图片

本目录提供 6 张可直接上传到 `/workspace` 的固定 seed 合成图片，用于本地复现工作台交互。它们来自项目内部批次 `visiondata-demo-seed-20260809-dirty`，不是生产现场数据，也不能作为模型精度或真实产线效果证明。

## 文件分组

### clear

- `clean-val-gear.png`
- `clean-val-bearing.png`
- `clean-test-bearing.png`

### quality_anomalies

- `q-blur.png`
- `q-underexposed.png`
- `q-overexposed.png`

## 安装版

1. 从 Windows 开始菜单打开 **VisionData Gate**，等待本地服务就绪。安装版不需要运行源码脚本，也不需要手工输入开发服务器地址。
2. 首次使用建立本地管理员账号；之后登录已有账号。选择有权限的工作区与项目，没有项目时先创建。无需为确定性图像检查配置外部模型 API。
3. 打开“图像工作簿”，使用“导入图像”选择本目录中 clear 和 quality_anomalies 文件夹里的 PNG。这些是合成样例，不是生产现场图片。
4. 选择图片，查看属性与像素剖面；需要标注时人工框选并保存。人工框不是模型预测，预览像素读数也不等于后端批次检查回执。
5. 如需执行检查，先完成用途、划分与标注要求，保存输入版本后再启动 Agent。以实际任务状态、证据和错误提示为准，不把打开页面当作执行完成。
6. 对发现的问题进行人工复核，再进入对应的整改流程。创建工单不等于已执行整改；生成派生数据并完成子版本重检后，才有新的检查结果。缺证据时允许保持 HOLD，不应为演示制造 PASS。

可选视觉训练还需要显式登记外部 Python、Torch、Ultralytics 和可信权重；它们不随核心安装包提供。未配置训练环境不妨碍使用已有的确定性数据检查。

## 源码版

仅在完整源码目录内运行 `run_workbench.ps1`；浏览器地址以启动输出为准。该脚本不是安装版资源，不能要求安装包用户寻找它。随后按上面的工作区、导入与人工复核流程操作。

若要体验重复账本，可将同一张图片再次上传。字节重复只证明 SHA-256 相同，不自动证明 Train/Val 泄漏。
